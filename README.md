# 課序｜家教排課・作業展示版

以 Vibe Coding 將家教固定課表、請假與調課協調整理成可操作的 Web App。本作品是「課序」MVP 的獨立純前端作業版本。

- **作品網站**：https://wqii77.github.io/tutor-schedule-demo/
- **規格書**：[SPEC.md](SPEC.md)
- **程式**：[index.html](index.html) — CSS／JavaScript 全部內嵌，沒有框架、CDN、後端或建置步驟。

## 建議評分流程（約 3 分鐘）

1. 老師端點「排課討論」→ 小禾 → 11/09 課程，接受家長提出的 11/10 18:00 候選；月曆及紀錄會更新。
2. 點「請假確認」→ 小晴 →「轉為調課」；案件離開請假確認，移入排課討論。
3. 切換「家長端」，選小晴，點 11/11 課程 → 提出候選 → 選日期／時間 → 送出。切回老師即可接受或拒絕。
4. 在學生頁新增或編輯虛構學生；切至 12 月 → 建立月份草稿 → 發布 → 切到該家長確認。
5. 到設定修改通勤 30／0 分鐘，觀察候選可選時段。週六小宇 12:00 下課，其他課程在 30 分鐘緩衝下最早 12:30；設 0 可相鄰。

要重複評分可按「重設展示資料」。展示時鐘固定為 2026/11/01，避免作品過幾天就無法操作。

## 展示版與正式 MVP 的差異

**這不是正式後端。** 資料是虛構樣本，儲存在此瀏覽器的 `localStorage`。不同裝置、瀏覽器或使用者不共享資料；角色切換是展示，不是真實登入或安全權限隔離。家長視角僅渲染選定學生的已發布課程，但全部樣本可在公開原始碼中查看。

沒有 D1、正式 API、伺服器版本驗證、真實多人 concurrency／409、家長能力連結或伺服器 Undo。Hold 與通勤只在本地狀態中運算。請勿輸入真實學生資料、電話、地址、密碼或金鑰。

正式 Next／React／D1 MVP 與私人程式碼庫沒有被取代，也沒有變更可見性。本公開 repo 只包含重新製作的匿名作業檔案與說明。

字體使用已安裝的昭源黑體／系統後備字體，不從外部下載字型。手機以課程清單取代密集七欄月曆，方便基本操作。

## 本機使用

下載 `index.html` 後直接以瀏覽器開啟即可。若瀏覽器禁止檔案頁面使用 localStorage，操作仍可在當次開啟中完成；重新開啟後不保證保留。

## GitHub Pages 設定

Settings → Pages → Source：Deploy from a branch → Branch：main → 資料夾：/(root) → Save。根目錄直接包含 `index.html`，不多包一層資料夾；無額外資源路徑。
